An AI agent's task log, drawn as a 1024x1024 PNG meme: it watered the plants, paid the bills, fired your boss — and replacing you is still "pending approval". The rogue agent is polite enough to wait for the user to click approve. Pure Python 3 stdlib (no dependencies, no network): `main.py` rasterises the robot face, the checklist and the pixel text, then encodes the PNG by hand with `zlib`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
